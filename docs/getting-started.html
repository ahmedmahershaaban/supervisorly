S Supervisorly ▶ Jump to “Run it”
Beginner's guide · no coding experience needed

Find a research supervisor — with proof for every fact.

Supervisorly is a small program you run on your own computer. You tell it a country and a field, and it builds you a tidy, filterable list of professors — where every single fact links back to the page it came from. This guide takes you from zero to your first result.

⏱ ~5 minutes 💳 Free — the demo needs no account 🔒 Runs on your machine 🌍 Any country, any field

What is this, really?

Imagine you want to do a PhD (or a master's, or a postdoc, or just research) and you need to find the right professor to work with. Normally you'd open dozens of tabs and copy notes into a document. Supervisorly does that legwork for you — politely and from public sources — and hands you a single web page you can filter and sort. Crucially, it never makes things up: if it can't find something, it tells you honestly instead of guessing.

What you'll need

Just three things. The offline demo (which this guide uses) needs no accounts and no payment.

✓A computer — Windows, Mac, or Linux all work.
✓Python 3.10 or newer — a free programming language. Download it from python.org/downloads and, on Windows, tick Add Python to PATH during install.
✓A “terminal” — a text window where you type commands. On Windows it's PowerShell; on Mac it's Terminal. Don't worry, you'll only paste a few lines.
New to the terminal?

A terminal is just a place to type instructions instead of clicking. You open it, type a command, press Enter, and it does the thing. That's the whole skill.

RUNRun it — five steps

Type (or paste) each block into your terminal and press Enter. Lines starting with # are just notes — you don't type those.

Get the files

Download the project to a folder on your computer. If you have git, run the first line; otherwise use the green “Code → Download ZIP” button on the project page and unzip it.

# get the code (or download the ZIP and unzip it)

Set up its own tidy workspace

This creates a private “virtual environment” (a sandbox for the program's parts) and installs what it needs. You only do this once.

terminal
# 1) make the sandbox
$ python -m venv .venv

# 2) turn it on — Windows:
$ .venv\Scripts\activate
# Mac / Linux instead:
$ source .venv/bin/activate

# 3) install the tool
$ python -m pip install -e ".[dev]"

(Optional) Check it's healthy

4

Run the demo scan

This is the fun part. The --demo flag runs a safe, offline example with made-up professors (no real people, no internet needed) so you can see exactly what the tool produces.

It just created two files in an output folder: a dashboard.html (the page you'll open) and a dashboard.json (the same data, for programs to read).

The four honest states

This is the heart of the tool. A blank cell can mean very different things, so Supervisorly never leaves you guessing — each field is one of four clearly-labelled states:

a real value
We found it, and here's the proof. Shown with its quote and a source link. This is a fact you can trust and click through to verify.
— we looked, found nothing
We checked the right places and there genuinely was nothing. An honest empty — not a bug, not laziness.
· not checked yet
We haven't looked here. Different from “found nothing.” It tells you where more digging could still help.
⏳ awaiting your browser
This page is behind a login or a bot-wall. The tool won't sneak past it — it hands the task to you (see “the human rung” below).
Why this matters

Most tools show a blank and let you assume the worst. Supervisorly's promise is the opposite: if a fact is shown, it's backed by a quote you can check; if it's missing, you're told exactly why.

Set up a live scan (real professors)

How a live scan works — read this first

The live scanner reads real professor pages and open research databases. You describe what you're looking for in plain words, the tool maps your field to a menu of research topics (built live from open data — never a fixed list), you tick the ones you want, and only then does the scan run. When an AI agent drives the tool, its browser tier also reads pages for you — including ones behind a login you own (see step C) — politely and at a walking pace, so no account is ever flagged.

In short: try the demo first to learn the output; then do the setup below and run for real.

A

Good news: no keys to sign up for

The two data services the tool uses are free and open — nothing to register for:

✓ROR (a registry of universities, ror.org) — its data is open; no key at all.
✓OpenAlex (open research data, openalex.org) — free; it just likes to know who's calling.
The only thing you provide

Your own email address — any one you own. It puts you in OpenAlex's faster “polite pool” and is how the tool politely identifies itself to servers. That's it. (There's an optional paid OpenAlex plan for very heavy use, but you don't need it.)

B

Tell the tool your email

You set one environment variable — a named box your terminal remembers. Paste the block for your system (put your real email between the quotes).

PowerShell — Windows
# this terminal session only:
$ $env:SUPERVISORLY_CONTACT_EMAIL = "you@example.com"

# to make it permanent (then reopen the terminal):
$ setx SUPERVISORLY_CONTACT_EMAIL "you@example.com"
Terminal — Mac / Linux
$ export SUPERVISORLY_CONTACT_EMAIL="you@example.com"
# add that line to ~/.zshrc or ~/.bashrc to keep it
If you forget it

You can't run it anonymously by accident. The tool stops and tells you to set your email — being a polite guest of these free services is part of the deal. (An optional paid OpenAlex key goes in SUPERVISORLY_OPENALEX_KEY if you ever want higher limits.)

C

Plan, then run a live scan

First, map your field to a topic menu and open the Scan Studio — a one-file, offline wizard where you pick your intent, country, and the topics to keep, and download a plan. Then scan from that plan. (Chatting with the agent instead? It does the same steps in conversation — you pick topics from a numbered list.)

terminal
# 1. map your field to a topic menu
$ python -m supervisorly map-field --field "causal ML"

# 2. open the Scan Studio wizard, tick topics, click “Export plan”
$ python -m supervisorly studio --map output/subject_map.json

# 3. scan from the exported plan
$ python -m supervisorly scan --plan supervisorly_plan.json --out output/live-dashboard.html

It reads only public pages and open databases and obeys every site's robots.txt. When the agent drives it, its own browser reads pages for you — on the first run it will pause and ask you to log into the walled sites (like X or LinkedIn) once, yourself, in the Chrome window it opens; after that it reads your advertised-profile pages on its own, slowly and politely. Anything it still can't read goes to you, the human rung, below.

Running it automatically, later

Supervisorly is built for repeat runs. A monthly re-scan reuses everything that hasn't changed (a “warm cache”), so it's fast and cheap and only looks at what's new. You can schedule that with Windows Task Scheduler or a cron job to keep your shortlist fresh on its own.

When a page is behind a login — “the human rung”

Some pages (like X/Twitter, or a university directory that needs a login) can't be read by a program without breaking the rules. Supervisorly refuses to do that. When the agent drives the tool, its browser (logged in once by you) reads most of these itself; whatever it can't — or anything that looks like a challenge or block — it politely passes to you:

The tool marks that field ⏳ awaiting your browser and writes you a ready-to-paste prompt.
You open the page yourself (e.g. with Claude for Chrome) — where you're logged in and allowed.
You paste the short result back into the tool.
It fills the gap and rebuilds your dashboard — without re-doing any of the earlier work.

You're always in control, and nothing is ever accessed that you couldn't access yourself.

It plays fair

This tool is built to be respectful of both websites and people. In plain terms:

✓Obeys each website's robots.txt rules, and slows down so it's never rude to a server.
✓Anyone can ask to be excluded — an opt-out list is honoured before anything is fetched.
✓Never bypasses a login, and never sends mass emails or auto-messages.
✓Your results stay on your machine — nothing is uploaded or shared without you.

If something goes wrong

The usual first-time snags, and the quick fix for each.

“python is not recognized / command not found”
Python isn't installed, or wasn't added to your PATH. Reinstall from python.org and tick Add Python to PATH. On Mac/Linux, try python3 instead of python.
The install fails or seems “locked”
Make sure the sandbox is turned on first (Step 2 — you should see (.venv) at the start of your prompt), then re-run the pip install line. The sandbox avoids permission problems.
The dashboard opens but is blank
You probably opened dashboard.json (the raw data) instead of dashboard.html (the page). Double-click the .html file. It works fully offline — no internet required.
“Missing credentials” when I try a live scan
That's the tool being honest: a live scan needs your contact email (step B above) — ROR and OpenAlex themselves are free and keyless. Set the email, or just keep using scan --demo to explore. The message tells you exactly what is missing and how to set it.
Nothing here matches my exact command
Run python -m supervisorly --help to see every available command, or read the README in the project folder for the full details.
